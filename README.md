# Deen aur Dunya — web app

Offline-capable web (PWA) build of the Deen aur Dunya app. Open the site once while online; after that it works offline.

Content sources (also listed inside the app under More → About & sources):
- Quran text: Tanzil Project — https://tanzil.net (verbatim, unmodified)
- Urdu translation: Maulana Fateh Muhammad Jalandhari, digital text from Tanzil (non-commercial use)
- City locations: GeoNames (geonames.org), CC BY 4.0
- Magnetic declination: World Magnetic Model WMM2025, NOAA NCEI (U.S. Government material, not subject to copyright protection)
- Fonts: Plus Jakarta Sans, IBM Plex Sans Arabic, Amiri, Amiri Quran, Noto Nastaliq Urdu, Noto Naskh Arabic, Noto Sans Devanagari, Noto Sans — SIL Open Font License 1.1
- Icons: Phosphor Icons (MIT); a few Material Icons glyphs drawn by Flutter's own widgets (Google, CC BY 4.0)

This repository contains only the compiled web build.
